# ZEsarUX - Spectrum and Related Z80 Machines

## Pick One Computer

The menu can list several systems. Start with the Spectrum model your file needs, not with a tour of every machine. Set the ROM for that model, boot to its own screen, and only then open a tape. If you switch machines, switch the ROM too. Leaving yesterday's firmware selected is how a file looks corrupt.

Joystick, border, and fast load options are per title. Save them on the game when they differ. A global fast-load that breaks one loader should not stay on for the whole library.

## What Changes per Machine

| Machine | You set |
|---|---|
| 48K or 128K Spectrum | The matching ROM and the tape |
| Another Z80 computer in the list | That computer's ROM, not the Spectrum one |
| Tape or snapshot | A file you may use |
| Joystick | Only if the game used one |
| Filter | After the program runs |

## Steps

1. Select the computer.  
2. Point at a ROM you may use for that computer.  
3. Boot to its screen.  
4. Load one program.  
5. Store odd settings with that program.  
6. Return to a known-good Spectrum game if a new file fails, before you blame the emulator.

## Fixes

The screen is not the machine you selected. The ROM is still the previous computer.  
A tape will not load. Use the loader and turn off acceleration.  
A 128K title fails on 48K. Change the model.  
Sound crackles only with a filter. Disable it.  
You wanted the C64 or CPC. Those are different emulators.

## One Known Tape

Keep a short program that already reaches its menu. Load it after any ROM or model change. If it fails, undo that change. If it runs, the new tape is the thing to inspect. Snapshots are optional resumes. Keep the tape file as the copy you can describe.

## Switch the ROM When You Switch the Computer

The menu can leave the previous machine's firmware selected. A new file then looks corrupt. After you change computers, open the ROM path and boot to that machine's own screen before you load a tape. A known-good Spectrum program is the control. Acceleration stays off for loaders that fail.

| Left selected | Result |
|---|---|
| Previous ROM | Wrong screen |
| Fast load | A tape that never starts |
| 48K for a 128K file | A crash |
| Control program fails | Undo the last change |
